[A9] — Rollup semantics chosen where DOC 3 is silent. Live layer = one row per alert at its target LOCATION only (mass = that location's item probability x timing.p120 from the alert's anchor complaint's latest forecast, count 1); cells and districts are summed from locations at query time via the geo catalog, so two alerts sharing a cell never double-count the cell's mass. Potential layer = every forecast's cell AND location rows (mass = prob x p120), alert_count = 1 per contributing forecast, decayed at query time by policy heatmap.decay_half_life_hours over potential_lookback_hours; above location level it reads only its cell rows (a forecast's cell and location levels describe the same mass). k-threshold therefore counts contributing forecasts for the potential layer. district lat/lon = mean of its cells' centroids. `from` is ignored for the potential layer (its window is `to` minus the lookback).

[A10] — Budget. Priority = confidence x log1p(amount) x interception_probability (the assessment's own; the policy floor if a caller's assessment has none), stored on the Alert with its `budget_rank`.
