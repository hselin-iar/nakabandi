# Frontend Operational Command Patterns Research

## Findings by Question

- **Triage Cockpits (Q1):** *Telebugs (Silin, 2023)* – A closed-source keyboard-first error-tracking tool using React+Tailwind. Implements a pure-keyboard triage inbox: `J`/`K` to move rows, `O` to open an alert, `X` to select. Includes a Command‑K palette for commands and data tables behind every chart. Text and table layouts are compact, avoiding layout shifts.  Applies to NAKABANDI’s alert queue (e.g. **Triage Inbox**): use a stable stacked list/grid, high-contrast severity highlights, circular SVG countdown timers (using pure CSS/Canvas), and full keyboard navigation. **[UNVERIFIED]**

- **Network Graphs (Q2):** *Cytoscape React (mwri, 2020; MIT)* – A React wrapper for [Cytoscape.js](https://js.cytoscape.org/) (MIT). Supports complex multi-hop graphs, node clustering/expansion, weighted edges, and animated layouts. Allows embedding React components as nodes. Applies to NAKABANDI’s **Case Dossier** money-flow graphs: use Cytoscape for layered transaction trees with collapsible subgraphs and edge thickness denoting amounts. **[VERIFIED]**  
  *Vis Network (visjs, 2024; MIT/Apache)* – A dynamic network library using HTML5 Canvas. Offers built-in clustering, physics simulations, and camera pan/zoom animations. Ideal for entity-relationship visualization. Applies to **Mule Network Graph**: rapid interactivity with thousands of nodes, on-the-fly neighborhood expansion and animated focus on clicked clusters. **[VERIFIED]**  

- **Tactical UI & Aesthetic (Q3):** *TezosX UI (Trilitech, 2023; MIT)* – A Tailwind+Radix component library. Uses true-black background (`#030505`) and near-white text in dark mode. Pairs JetBrains Mono (tabular numbers) with a clean sans-serif (IBM Plex Sans). Muted warm-gray accents highlight data. Applies to **Command Center** styling: define CSS variables in `tailwind.config.js` for background/foreground (as TezosX does), enable `font-tnum` for tabular digits, and use subtle neon glows on icons or severity pulses.  
  *Terminal-Style UI (Zheng-Charlie, 2024; Demo)* – An unlicensed showcase of a “hacker console” theme. Uses **monospace typography throughout**, 100% black canvas, and minimal controls (pure text and icons). Suggests using `font-mono` and suppressing all non-data chrome. Applies to **High-Density Panels**: ensure numeric displays use monospaced fonts and tables align, with no extraneous labels or borders – a “no-fluff” look. **[UNVERIFIED]**  
  *Monospace Design System (Fosh, 2026; concept)* – A warm-dark design strategy. Chooses JetBrains Mono for numbers and warm-neutral palette. Emphasizes one accent color and generous color token customization. Though not open source, it underscores pairing a crisp monospace number font with a clean sans header and using soft neon highlights. Applies to overall theme: combine a monospaced UI font (e.g. `font-mono`) for data grids with muted UI buttons, and use animated focus/hover glows (via `ring-*` or custom CSS animations). **[UNVERIFIED]**

- **MapLibre Tactical Map (Q4):** *MAGK Tactical Map (MAGK, 2025; docs)* – Organizer’s real-time event map built on MapLibre GL JS. Uses **local vector tiles** (offline OSM/MapTiler) and draws overlays (polygons, lines, circles) interactively. Has live markers (latitude-longitude tracks) and “capture-radius” circles that expand on drag. Applies to **GIS Map**: load custom GeoJSON sources into MapLibre (no external tiles), overlay pulsating circles (via animated GeoJSON or CSS-driven `paint` properties) for alerts, and draw/update threat zones as circle layers (showing radius in meters) that update in real time. For example, MAGK’s editor shows circle radius and area as the user drags. **[VERIFIED]**

- **Kinetic Feedback (Q5):** *Optimistic UI (Crystallize Tech, 2025)* – Guides instantaneous feedback: update the UI immediately on user action, then confirm with server. E.g. increment displayed counters (funds frozen, cases created) before the API call returns. *Telebugs UI (Silin, 2023)* – Emphasizes **removing delays**: “does not try to make triage flashy… remove the little pauses” between action and understanding. Applies to NAKABANDI actions (freezing accounts, dispatch): trigger transient toasts for each step (e.g. “Account flagged → Funds frozen → Patrol dispatched”), animate numeric stats (counter bar graphs increment by ₹ amounts). Use libraries like React‑Toastify (MIT) for cascading toasts, and CSS transitions (e.g. Tailwind’s `transition-all`) for bar/number changes. Ensure feedback is immediate (optimistic) and then gracefully handle errors (rollback or error toast). **[VERIFIED]**

## Top 3 Recommended Projects / Boilerplates

- **Utima UI** – [utima-solutions/ui](https://github.com/utima-solutions/ui) (Utima Solutions, 2024, MIT). A monorepo of React components built on shadcn/ui and Radix primitives. Offers high‑level, customizable building blocks (tables, forms, dialogs) with Tailwind theming. Study its structure and dark theme for NAKABANDI’s cockpit components.  
- **Vis Network** – [visjs/vis-network](https://github.com/visjs/vis-network) (visjs organization, 2024, Apache-2.0/MIT). A robust network graph engine. Use it as a reference for rendering large forensic graphs: it natively handles clustering and animations. Its HTML5 Canvas approach suggests patterns for performance.  
- **shadcn/ui** – [shadcn-ui/ui](https://github.com/shadcn-ui/ui) (shadcn, 2024, MIT). A comprehensive, MIT‑licensed Radix+Tailwind component library. Explore its component implementations (tables, modals, etc.) and theming. Copy its typography tokens (e.g. `font-tnum`) and dark-mode config for a high-density, polished UI.

## Executive Summary

- **Keyboard-First Triage:** Implement a fixed, virtualized alert list (no layout shifts), with `J/K` navigation and on-spot countdown circles (SVG/CSS timers) per row. Use urgent color pulses (CSS animations) and audible alerts for new high‑priority items.  
- **Forensic Graphs:** Use Cytoscape or vis-network to display transaction chains. Represent transfer amounts as edge width and timestamps by animation over a slider. Allow collapsing nodes to aggregate lower hops. Real-time filtering (using TanStack Query) should update the graph smoothly.  
- **Dark, High-Density Theme:** Base colors on near-black backgrounds and off-white text. Apply `font-mono` with tabular-nums for all numeric fields to align columns. Use subtle accent glows (e.g. `ring-amber-500/50`) on interactive elements. Disable all unneeded whitespace and icons: every pixel shows data.  
- **Offline Map Interactions:** Pre-bundle GeoJSON tiles for India. Add canvas-animated “ping” markers for alerts (a growing/fading circle on coordinates). Use MapLibre’s circle layers to draw dynamic threat/response radii (updating on SSE events). Provide manual drawing tools like MAGK for delineating zones.  
- **Instant Feedback:** Adopt **optimistic updates**: when freezing funds or dispatching units, immediately reflect changes in UI without waiting (Crystallize-style). Trigger sequential toasts (e.g. “Funds frozen +100k”, then “Patrol en route”) with short life. Animate statistic increments (e.g. an account’s frozen total count going up) and light up associated map markers instantly. Eliminate “waiting…” states – use spinners only if strictly necessary.  

## What I Could Not Confirm

- No permissive‑license UI was found specifically for real-time alert triage with time-decay and countdowns. (FalconEye and Telebugs demos exist, but are AGPL/closed.) We would likely need to custom-build the countdown/priority UI.  
- There are no open-source samples of forensic crypto-network UIs (Chainalysis/Palantir prototypes are proprietary). We extrapolate from generic graph libraries.  
- Some micro-interaction details (e.g. ideal animation easing or exact glow intensity) are product-specific and not documented openly. These will require design iteration.  
- Offline isochrone routing or dynamic heatmap layers in MapLibre (for GIS route planning) are complex; no simple open example was found. Might need to approximate with precomputed vectors.
